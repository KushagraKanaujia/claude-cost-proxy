Claude Cost Proxy

A small local proxy that sits between Claude Code and the Anthropic API. It logs tokens and the estimated dollar cost of every request, and answers exact repeat questions from a cache so you don't pay twice.

How it works

Claude Code
ANTHROPIC_BASE_URL
= http://localhost:8080
→
claude-proxy
hash request · check cache
log usage & cost
→
api.anthropic.com
only on a cache miss
  • Every POST /v1/messages is hashed (model, system prompt, messages, tools, settings).
  • On a miss it is forwarded unchanged. Normal JSON and streamed (SSE) responses are both passed straight through, and token usage is read from the response.
  • Responses with no tool use are cached for 24 hours. File edits and shell commands are never cached.
  • A cached answer is skipped if a file path mentioned in the prompt has been modified since it was cached.
  • Each request becomes a line in ~/.throttle/logs/throttle-YYYY-MM-DD.jsonl; claude-proxy-summary totals today and the last 7 days.

Use it for real

pip install git+https://github.com/KushagraKanaujia/claude-cost-proxy
claude-proxy-setup      # saves your Anthropic API key, points Claude Code at the proxy
claude-proxy            # keep this running
claude-proxy-summary    # see what you've spent and saved

Requires an Anthropic Console API key (pay-as-you-go). The proxy itself is free and MIT licensed. Prices in the proxy are list-price estimates, not your bill.
